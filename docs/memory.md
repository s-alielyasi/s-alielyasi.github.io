# حافظهٔ پروژه

تاریخ اسکن اولیه و آخرین بازبینی: **۲۰۲۶-۱۰-۱۵**. این سند مرجع وضعیت فعلی سورس است؛ وضعیت کارهای تکمیل‌شده و بررسی‌های باقی‌مانده در [status.md](status.md) نگه‌داری می‌شود. تاریخچهٔ جزئی تغییرات در گیت موجود است.

## هدف و معماری

سایت شخصی علی الیاسی با تمرکز بر مدیریت محصول، نرم‌افزار و کیفیت است. تنها صفحهٔ HTML چهار بخش خانه، رزومه، تماس و ثبت سفارش دارد. رابط اصلی فارسی با `lang="fa"` و `dir="rtl"` است؛ عنوان انگلیسی داخل صفحه جهت و زبان مستقل دارد.

پیاده‌سازی HTML، CSS و JavaScript ساده است. backend، پایگاه داده، فریم‌ورک، package manager یا مرحلهٔ build ندارد. فونت رسمی در مخزن نگه‌داری می‌شود و نصب پکیج یا اتصال به CDN برای اجرای سایت لازم نیست. پردازش سفارش و پرداخت در سرویس‌های بیرونی انجام می‌شود.

## محتوا و رفتار

- پنل‌های `st-panel-1` تا `st-panel-4` به‌ترتیب خانه، رزومه، تماس و ثبت سفارش‌اند. خانه یک `h1` دارد و سه بخش دیگر `h2` دارند.
- رزومهٔ فارسی و فایل آن حذف شده‌اند. PDF انگلیسی با فایل `Ali-Elyasi-Resume-B2C.pdf` ارائه‌شده توسط مالک جایگزین شده و مسیر عمومی قبلی آن حفظ شده است. `pdfinfo` رمزگذاری یا JavaScript در این فایل گزارش نمی‌کند.
- تماس شامل Telegram، LinkedIn، GitHub، Virgool و Goodreads است. Zeeg، Stackshare، Spotify و Clubhouse حذف شده‌اند؛ لینک Twitter از README حذف شده است.
- سفارش به Google Forms و پرداخت به Zarinpal لینک دارد. هر شش لینک بازشونده در تب جدید `rel="noopener noreferrer"` دارند. رزومه و دو خدمت با لینک‌های کلاس `action-link` نمایش داده می‌شوند و عنصر تعاملی تو‌در‌تو ندارند.
- چهار لینک `.st-push` داخل `nav` به شناسهٔ پنل‌ها می‌روند؛ جابه‌جایی به‌صورت بومی و بدون JavaScript نیز کار می‌کند. `main`، لینک پرش به محتوا، فهرست معنایی تماس و فوکوس قابل مشاهده وجود دارند.
- JavaScript پنلی را فعال می‌کند که ابتدای آن از خط ۴۰٪ ارتفاع viewport گذشته است. وضعیت با `aria-current="location"` اعلام می‌شود؛ scroll با `requestAnimationFrame` تجمیع می‌شود و resize، hashchange، pageshow و آماده شدن فونت نیز آن را به‌روز می‌کنند. جابه‌جایی پیکسلی پنل‌ها و متغیر global ضمنی نسخهٔ اولیه حذف شده‌اند.

## چیدمان واکنش‌گرا

- رنگ اصلی `#0d9b9b` و رنگ فعال `#086f6f` است؛ پنل‌ها پس‌زمینهٔ سفید و فیروزه‌ای متناوب دارند.
- صفحه اسکرول طبیعی دارد. حداقل ارتفاع پنل `100svh` با fallback به `100vh` است و با محتوا رشد می‌کند. `overflow: hidden` پنل تزئین را محدود می‌کند؛ `body` اسکرول را مسدود نمی‌کند.
- نوار پایین حداقل `3.5rem` ارتفاع به‌علاوهٔ safe area دارد و در فاصلهٔ پایین پنل‌ها برای آن جا رزرو شده است. عناصر لمسی ناوبری، تماس و دکمه‌ها حداقل ۴۴px ارتفاع دارند.
- عنوان‌ها، فاصله‌ها و تزئین با `clamp` تنظیم می‌شوند. در عرض حداکثر `36rem` دکمه‌ها تمام‌عرض می‌شوند. در حالت افقی با ارتفاع حداکثر `38rem` تزئین و فاصله‌ها کوچک‌تر و تماس‌ها دو ستونه می‌شوند.
- متن قابل انتخاب است؛ اسکرول نرم با `prefers-reduced-motion` غیرفعال می‌شود. وجود این قواعد، جایگزین ارزیابی کامل دسترس‌پذیری نیست.

## فونت و اعداد فارسی

نسخهٔ **Farsi-Digits** پکیج اصلی `vazir-font@30.1.0` با نام CSS برابر `Vazir FD` استفاده می‌شود. وزن‌های ۱۰۰، ۳۰۰، ۴۰۰، ۵۰۰، ۷۰۰ و ۹۰۰ فایل WOFF2 و fallback WOFF مستقل و `font-display: swap` دارند. مسیر فایل‌ها نسبت به `assets/fonts/vazir/font-face.css` است.

فایل‌های فونت از `dist/Farsi-Digits/` آرشیو رسمی پس از تطبیق SHA-512 کپی و با اصل تطبیق بایتی داده شده‌اند. TTF قدیمی و variant استاندارد جایگزین شده‌اند. `OFL.txt` و `AUTHORS.txt` بدون تغییر حفظ شده‌اند؛ منبع و integrity در [README فونت](../assets/fonts/vazir/README.md) ثبت شده‌اند.

ارقام ASCII در متن نمایشی با شکل فارسی فونت دیده می‌شوند؛ شماره‌های تزئینی HTML نیز `۱` تا `۴` هستند. اعداد URLها، شناسه‌ها، JavaScript و metadata برای فارسی‌سازی نمایش تغییر داده نشده‌اند. مجوز فونت از مجوز کد پروژه مستقل است.

## عنوان و SEO

- عنوان تب مرورگر، Open Graph و عنوان انگلیسی قابل مشاهده: `Ali Elyasi | Product Manager, Software & Quality`.
- تنها تیتر اصلی: `علی الیاسی | مدیریت محصول، نرم‌افزار و کیفیت`. عنوان انگلیسی زیر آن با `lang="en"` و `dir="ltr"` نمایش داده می‌شود.
- description دقیقاً متن ارائه‌شده توسط مالک است و در meta description، Open Graph و JSON-LD یکسان است. در تغییر بعدی این سه مقدار باید هماهنگ بمانند.
- canonical، `og:url`، JSON-LD و sitemap از `https://ali-elyasi.ir/` بر اساس `CNAME` استفاده می‌کنند. تصویر Open Graph نشان AE موجود با URL مطلق و اطلاعات نوع، اندازه و alt است.
- JSON-LD شامل `WebSite`، `ProfilePage` و `Person` با نام، نقش مدیریت محصول و لینک‌های LinkedIn و GitHub موجود در صفحه است.
- robots دسترسی را باز می‌گذارد و به sitemap اشاره می‌کند. sitemap فقط URL اصلی را دارد؛ پنل‌های hash، مستندات و لینک‌های بیرونی به‌عنوان صفحه اضافه نشده‌اند. تاریخ حدسی `lastmod` وجود ندارد.
- منابع اجرای قبلی: [عنوان صفحه](https://developers.google.com/search/docs/appearance/title-link)، [canonical](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls)، [sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)، [Open Graph](https://ogp.me/) و [ProfilePage](https://schema.org/ProfilePage).

## اجرای محلی و انتشار

از روت پروژه:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

صفحه در `http://127.0.0.1:8000` در دسترس است. فایل‌های روت مستقیم سرو می‌شوند؛ نصب یا build لازم نیست. مخزن workflow انتشار، تنظیمات build، `.nojekyll` یا فایل مستقل مجوز کد ندارد. نبود این فایل‌ها به‌تنهایی الزام به اضافه کردنشان نیست.

`CNAME` با GitHub Pages سازگار است، ولی منبع انتشار، DNS، HTTPS و نسخهٔ زنده از checkout محلی قابل تأیید نیستند. در روند کاری فعلی فقط کامیت محلی انجام شده و push/deploy اجرا نشده است؛ وضعیت پیگیری در [status.md](status.md) آمده است.

## بررسی‌های ثبت‌شده و حدود آن‌ها

این نتایج متعلق به تسک‌های اجرایی قبلی همین روند کاری‌اند و در بازبینی مستندات دوباره در مرورگر اجرا نشده‌اند:

- Firefox 136 با HTTP محلی در ۱۱ viewport بررسی شده است: `320×640`، `360×640`، `390×844`، `430×932`، `576×800`، `768×1024`، `820×1180`، `1024×768`، `1440×900`، `640×360` و `844×390`.
- با عنوان و فونت FD فعلی، چهار پنل، ناوبری و وضعیت فعال، بارگیری فونت، نبود overflow افقی و clipping محتوا و ارتفاع هدف‌های لمسی بررسی شده‌اند. تصاویر نماینده دیده شده‌اند؛ شکل ارقام ASCII و فارسی FD نیز بصری بررسی شده است.
- افزایش اندازهٔ فونت روت به ۲۰۰٪ در عرض ۳۲۰px، دسترسی به آخرین دکمهٔ سفارش، فعال‌سازی ناوبری با Enter و ناوبری با JavaScript غیرفعال بررسی شده‌اند. این آزمایش، بزرگ‌نمایی کامل مرورگر یا آزمون دستگاه واقعی نبوده است.
- PDF، فونت، مجوز، robots و sitemap با HTTP محلی و تطبیق محتوا بررسی شده‌اند. عنوان‌ها و description، یکسان بودن URLها، JSON-LD و ارجاع‌هایش، XML sitemap، قواعد robots، شناسه‌ها و مسیرهای HTML/CSS نیز بررسی شده‌اند.
- قواعد ignore برای ۱۵ مسیر عمومی/نمونه و ۲۱ مسیر محلی/حساس در تسک اولیه بررسی شدند. اسکن الگویی متن‌های trackشدهٔ اولیه نشانه‌ای از قالب‌های بررسی‌شدهٔ اعتبارنامه پیدا نکرد؛ تاریخچهٔ کامل اسکن نشده است.
- تست خودکار، linter یا CI داخل مخزن وجود ندارد. اسکریپت‌های بررسی قبلی موقت و خارج مخزن بودند و جزو ابزارهای قابل اجرای checkout نیستند. بررسی مرورگرهای دیگر، دستگاه واقعی، صفحه‌خوان و سرویس‌های زنده در [status.md](status.md) ثبت شده است.

## فایل‌های عمومی

سورس، فونت، لوگو، PDF لینک‌شده و مستندات محتوای عمومی مخزن‌اند. `.gitignore` فایل‌های محیط واقعی، کلیدهای رایج، پوشهٔ محلی AWS، cache، log، خروجی ابزارها و تنظیمات شخصی ویرایشگر را پوشش می‌دهد؛ وجود الگوی ابزار به معنی نصب آن نیست. نمونه‌های `.env.example` و `.env.*.example` فقط باید مقدار نمونه داشته باشند.

اطلاعات شخصی رزومه در مستندات تکرار نمی‌شود. حذف فایل یا ignore کردن، تاریخچهٔ گیت را پاک نمی‌کند؛ رزومهٔ فارسی فقط از نسخهٔ فعلی حذف شده و تاریخچه بازنویسی نشده است.

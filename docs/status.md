# وضعیت پروژه و کارهای باقی‌مانده

تاریخ بازبینی: **۲۰۲۶-۱۰-۱۵**. مبنای گزارش، سورس و مستندات مخزن محلی و بررسی‌های ثبت‌شده در همین روند کاری است. این گزارش به معنی بررسی زندهٔ GitHub، دامنه یا سرویس‌های خارجی نیست.

## درخواست‌های تکمیل‌شده

| درخواست | وضعیت موجود در مخزن |
| --- | --- |
| اسکن، راهنمای عامل‌ها، حافظه و قواعد ignore | `AGENTS.md`، `docs/memory.md` و `.gitignore` موجود و بازبینی شده‌اند |
| بهینه‌سازی ساختار | CSS، JavaScript، فونت و تصویر زیر `assets/` قرار دارند و ارجاع‌ها هماهنگ‌اند |
| رزومه | تنها PDF انگلیسی B2C ارائه‌شده توسط مالک در مسیر عمومی قبلی قرار دارد؛ فایل و لینک رزومهٔ فارسی حذف شده‌اند |
| حذف لینک‌ها | Zeeg، Stackshare، Spotify و Clubhouse از تماس و Twitter از README حذف شده‌اند |
| فونت اصلی و ارقام فارسی | شش وزن رسمی Farsi-Digits وزیر 30.1.0 همراه مجوز و attribution محلی‌اند |
| موبایل و تبلت | چیدمان سیال، RTL، اسکرول طبیعی، ناوبری لینک‌محور و حالت افقی پیاده‌سازی و در Firefox بررسی شده‌اند |
| عنوان‌ها و SEO | عنوان انگلیسی، تیتر فارسی و description درخواستی اعمال شده‌اند؛ canonical، Open Graph، JSON-LD، robots و sitemap موجودند |
| کامیت مرحله‌ای | پیاده‌سازی در کامیت‌های `87eaa13`، `10e908d` و `be609ea` ثبت شده است |
| مجوز کد | با واگذاری انتخاب توسط مالک، مجوز MIT برای کد و مستندات توسعه اضافه شد؛ OFL فونت و استثنای محتوای شخصی حفظ شدند |

در محدودهٔ درخواست‌های اجرایی قبلی، کار شناخته‌شده‌ای نیمه‌کاره نمانده است. موارد زیر بررسی‌های تکمیلی یا تصمیم‌های بعدی هستند.

## بررسی‌های تکمیلی انجام‌نشده

| موضوع | آنچه هنوز تأیید نشده | معیار پایان |
| --- | --- | --- |
| انتشار و دامنه | در این روند کاری push/deploy انجام نشده؛ تنظیمات GitHub Pages، DNS، HTTPS و محتوای نسخهٔ زنده تأیید نشده‌اند | تأیید منبع انتشار و دسترسی نسخهٔ مطلوب روی دامنه، شامل فونت، رزومه، robots و sitemap |
| مرورگر و دستگاه | تست قبلی روی Firefox دسکتاپ با اندازه‌های شبیه‌سازی‌شده بوده؛ Safari، Chrome و دستگاه واقعی بررسی نشده‌اند | بررسی موبایل و تبلت واقعی، چرخش، ناحیهٔ امن و دسترسی به محتوا و دکمه‌ها |
| دسترس‌پذیری تکمیلی | Enter و متن بزرگ بررسی شده‌اند؛ صفحه‌خوان، چرخهٔ کامل Tab و بزرگ‌نمایی کامل مرورگر ارزیابی نشده‌اند | بررسی ترتیب و وضوح فوکوس، خواندن عنوان‌ها و ناوبری و دسترسی در بزرگ‌نمایی |
| مقصدهای بیرونی | اعتبار فعلی لینک‌های تماس، فرم سفارش و صفحهٔ پرداخت تست نشده است | باز شدن مقصدهای موردنظر و تأیید مالکیت/محتوای آن‌ها؛ بررسی مقصد مستلزم ارسال فرم یا پرداخت نیست |
| SEO روی دامنهٔ زنده | ایندکس، URL انتخاب‌شدهٔ موتور جست‌وجو و نمایش پیش‌نمایش اشتراک‌گذاری تأیید نشده‌اند | بررسی پس از انتشار؛ وجود metadata در سورس به‌تنهایی نتیجهٔ زنده را اثبات نمی‌کند |

## تصمیم‌ها و توسعه‌های اختیاری

| موضوع | وضعیت و تصمیم لازم |
| --- | --- |
| هماهنگی محتوا با description | description درخواستی از نوشته‌ها، تجربه‌ها و پروژه‌ها نام می‌برد، اما صفحه فعلاً چهار بخش معرفی، رزومه، تماس و سفارش دارد. در تسک محتوا، افزودن آن بخش‌ها یا تغییر متن با نظر مالک تعیین شود؛ متن در این بازبینی تغییر نکرده است |
| بررسی‌های قابل تکرار | تست خودکار و CI در مخزن وجود ندارد؛ اسکریپت‌های بررسی قبلی موقت بودند. افزودن ابزار و مجموعه‌تست دائمی در صورت نیاز نگه‌داری تعیین شود |

نبود فریم‌ورک، package manager، build یا `.nojekyll` به‌تنهایی کار ناقص محسوب نمی‌شود؛ ساختار فعلی یک سایت استاتیک بدون مرحلهٔ ساخت است.

## حدود بازبینی مستندات

README روت، راهنمای عامل‌ها، حافظهٔ پروژه، README فونت و فایل‌های اصلی attribution/مجوز با سورس تطبیق داده شدند. مسیرها و لینک‌های محلی، مشخصات PDF، خانواده و وزن‌های فونت، عنوان‌ها، description و مقادیر SEO بررسی شدند. در این تسک فقط مستندات تغییر کردند؛ تست مرورگری یا بررسی زنده دوباره انجام نشد.

## بررسی‌های بازبینی ساختار پیش از بازطراحی

- نقش فایل‌های trackشده، مصرف اسکریپت‌ها در فرمان‌های npm، تست‌ها و workflow و فهرست مجاز فایل‌های عمومی بررسی شد. فایل‌های توسعه وارد artifact نمی‌شوند.
- ارجاع‌های محلی مستندات و فرمان‌های مستندشده با فایل‌های پروژه تطبیق داده شدند؛ ارجاع به پیش‌نویس حذف‌شده باقی نماند. `git diff --check` بررسی شد.
- وضعیت PR، اجرای Actions و برنچ‌های ریموت از GitHub خوانده و فایل‌های نسخهٔ زنده با روش بالا تطبیق داده شدند. در این بازبینی عملیات ایجاد PR، اجرای workflow یا انتشار انجام نشد.
- تغییرات این بازبینی به مستندات و حذف پیش‌نویس PR محدود است. تست‌های npm و مرورگر در این تسک دوباره اجرا نشدند؛ `node` و `npm` در PATH محیط عامل موجود نیستند. نتیجهٔ CI موجود، اجرای تست جدید روی این برنچ محسوب نمی‌شود.

## نتایج تست‌های ثبت‌شدهٔ قبلی

این نتایج مربوط به مرحلهٔ پیشین توسعه در **۲۰۲۶-۱۰-۱۵** هستند:

- **۴۸ تست مرورگر بدون شکست و retry** در Ubuntu 24.04 با Chrome 155، Firefox 157 و WebKit 27.2 ثبت شده است؛ پروژه‌ها شامل دسکتاپ و شبیه‌سازی Android، iPhone و iPad بودند. Chromium به دلیل محدودیت دریافت مرورگر، از Google Chrome نصب‌شده استفاده کرد.
- چهار بخش، ناوبری، حالت افقی، overflow و clipping، Tab و Enter، لینک پرش، فوکوس، JavaScript غیرفعال، متن ۲۰۰٪ در عرض ۳۲۰px، metadata و assetها بررسی شدند. axe در قواعد انتخاب‌شدهٔ WCAG نقضی گزارش نکرد؛ این نتیجه آزمون انسانی صفحه‌خوان یا گواهی انطباق کامل نیست.
- بزرگ‌نمایی واقعی ۲۰۰٪ Firefox 136 جداگانه بررسی شد؛ دسترسی به بخش‌ها و آخرین دکمه بدون overflow افقی ثبت شده است.
- **۵ تست HTTPS محلی** با `npm run test:release` گذشتند: پذیرش خروجی یکسان، رد عنوان/HTML/CSS قدیمی و رد HTTP ساده. TLS عمومی غیرفعال نشد.
- `npm run check`، بسته‌بندی `dist/`، هماهنگی manifest/lockfile، ساختار workflow و قفل SHA اکشن‌ها بررسی شدند. گزارش مرورگر خروجی محلیِ ثبت‌نشده در گیت است؛ گزارش CI از اجرای مربوط در GitHub دریافت می‌شود.

### تغییرات و بررسی‌های تسک ۱

- معرفی دوخطی داخل یک `h1`، متن انگلیسی مستقل، معرفی کوتاه، دو CTA رزومه/تماس و سه کارت تجربه‌ها، پروژه‌ها و نوشته‌ها مطابق راهنما پیاده شدند. آیکون‌های SVG تزئینی، لینک پایین کارت‌ها و فضای سفید انتهای خانه اضافه یا تنظیم شدند؛ لینک نوشته‌ها نشانهٔ تب جدید دارد.
- پایهٔ رنگ کارت و اقدام اصلی/outline در CSS مشترک تعریف شد. لینک‌های خانه برای متن بزرگ فاصلهٔ اسکرول دارند و JavaScript فقط در فوکوس قابل‌مشاهدهٔ کیبورد، عنصر پوشیده‌شده را به فضای بالای نوار پایین می‌آورد. این رفتار برای Firefox لازم بود و با کلیک ماوس جابه‌جایی اضافی ندارد.
- `npm run check` و `npm run build` با Node.js نسخهٔ 22.23.3 موجود در محیط موقت گذشتند. اجرای نهایی `npm test -- --workers=2 --retries=0` در کانتینر محلی Ubuntu 24.04 بدون شبکه، **۵۴ تست موفق، بدون شکست و بدون retry** داشت: Chrome، Firefox و WebKit دسکتاپ، موبایل شبیه‌سازی‌شدهٔ Chrome/WebKit و تبلت WebKit. تست‌های کلیک/تاریخچهٔ خانه و فوکوس هر پنج لینک با متن بزرگ نیز در همین مجموعه هستند؛ بررسی axe و ARIA خودکار است. گزارش HTML و خروجی‌ها در `playwright-report/` و `test-results/` محلی و ignoreشده قرار دارند. وابستگی یا ابزار تست جدیدی به مخزن اضافه نشده است.
- یک بررسی موقت با Playwright/Chrome در کانتینر محلی بدون شبکه در ۱۱ اندازه انجام شد: `320×640`، `360×640`، `390×844`، `430×932`، `768×1024`، `820×1180`، `1024×768`، `1440×900`، `1536×1024`، `640×360` و `844×390`. عرض/ارتفاع کارت‌ها، ترتیب RTL، هدف لمسی، overflow و دسترسی به لینک پایانی بررسی شدند؛ خطای JavaScript یا دریافت فایل محلی ثبت نشد. اسکرین‌شات‌های نماینده با طرح خانه تطبیق بصری داده شدند. این اسکریپت موقت جایگزین تست‌های دائمی مخزن نیست.
- متن ۲۰۰٪ در عرض ۳۲۰px و فوکوس هر پنج لینک خانه بررسی شد. این بررسی تغییر اندازهٔ فونت روت است؛ آزمون بزرگ‌نمایی واقعی مرورگر، صفحه‌خوان انسانی یا دستگاه فیزیکی در این تسک انجام نشده است.
- HTML سه بخش دیگر بدون تغییر باقی ماند و اسکرین‌شات‌های آن‌ها در `1440×900` و `390×844` با بارگذاری مستقل نسخهٔ قبل مقایسه شدند. ابعاد و محتوای آن‌ها حفظ شده است؛ در موبایل تغییر ارتفاع خانه، مبدأ اسکرول را ۰٫۶۲۵px جابه‌جا کرده و رندر متن قدری متفاوت است، بنابراین ادعای برابری پیکسلی همهٔ تصاویر مطرح نیست.
- فایل PDF، فونت و favicon و دیگر فایل‌های عمومی در بررسی محلی حفظ شدند. بررسی دسترسی زندهٔ ویرگول یا دیگر سرویس‌های خارجی در این تسک انجام نشده و پیام، فرم یا پرداختی ارسال نشده است. تصاویر بررسی محلی‌اند و وارد artifact عمومی یا گیت نمی‌شوند.
- مسیرهای محلی مستندات و `git diff --check` بررسی شدند. تحویل این تسک تغییرات محلی روی برنچ بازطراحی است؛ عملیات GitHub و انتشار انجام نشده است.

### تغییرات و بررسی‌های تسک ۵

- ریسپانسیو هر چهار بخش یکپارچه شد. دستاوردهای رزومه، لینک‌های ثانویهٔ تماس و خدمات سفارش با `auto-fit` و حداقل عرض `min(100%, 14rem)` به فضای لازم برای متن پاسخ می‌دهند؛ در فضای میانی دو ستون و با متن بزرگ در فضای محدود یک ستون می‌شوند. این تغییر، بیرون‌زدگی کارت‌های تماس در `640×360` با متن ۲۰۰٪ را برطرف کرد. توضیح، شناسه و فلش کارت‌های ثانویهٔ تماس تا `56rem` در ردیف‌های مستقل‌اند تا در تبلت هم خوانا بمانند.
- ماتریس دائمی سه موتور دسکتاپ به ۱۱ اندازهٔ `320×640`، `360×640`، `390×844`، `430×932`، `768×1024`، `820×1180`، `1024×768`، `1440×900`، `1536×1024`، `640×360` و `844×390` گسترش یافت؛ از هر چهار پنل تصویر به گزارش محلی پیوست می‌شود. پروژه‌های موبایل و تبلت نیز اندازهٔ اصلی و چرخیده را بررسی می‌کنند. متن واقعی، کارت‌ها، فاصله از لوزی، لینک پایانی بالای منو، hash مستقیم، اسکرول، resize، یکتایی وضعیت فعال و reduced motion پوشش دارند؛ back/forward و Tab/Enter در تست‌های موجود باقی مانده‌اند.
- متن ۲۰۰٪ در `320×640` و `640×360` همراه inset پایین شبیه‌سازی‌شدهٔ ۳۴px بررسی می‌شود. تست بدون JavaScript نیز متن بزرگ و انتهای سفارش را پوشش می‌دهد. در حالت افقی اگر خودِ یک لینک کارتی از فضای قابل مشاهده بلندتر باشد، محتوای آن با اسکرول قابل دسترسی است؛ ارتفاع ثابت یا کوچک‌کردن متن اعمال نشده است. آزمون فوکوس پس از کلیک/لمس ابتدا با Tab وارد حالت کیبورد می‌شود؛ آزمون اسکرول بدون JavaScript به میانبر متفاوت End در موتورهای مرورگر وابسته نیست. بیرون‌زدگی عمدی تزئین و امتداد جوهر فونت با overflow قابل‌مشاهده، بریدگی محتوا گزارش نمی‌شوند.
- بررسی موقت Playwright/Chrome برای ۴۴ ترکیبِ چهار پنل و ۱۱ اندازه نیز انجام شد؛ حداقل ارتفاع لینک‌های محتوایی ۴۴px و دسترسی به لینک آخر ثبت شد؛ بررسی جداگانهٔ همان ۱۱ اندازه نیز هیچ خطای console، JavaScript یا دریافت فایل محلی نداشت. اسکرین‌شات‌های نمایندهٔ موبایل، تبلت، افقی و متن بزرگ بصری بررسی شدند. محتوای داخلی تصاویر دسکتاپ `1536×1024` هر چهار صفحه با خروجی تسک ۴ یکسان است و ترکیب آن‌ها با تصاویر مرجع تطبیق داده شد. این اسکریپت موقت جایگزین تست دائمی checkout نیست؛ تصاویر وارد گیت یا artifact عمومی نمی‌شوند.
